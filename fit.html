Built on MERN

Four pieces, each doing one job. This is the map you'll follow once we start wiring pages together.

M

MongoDB

Stores users, workouts, nutrition and diet data as flexible documents.

E

Express

Defines the API routes — login, fetch-workout, log-meal, and so on.

R

React

Renders every screen you see — this landing page becomes one of many.

N

Node.js

Runs the server so Express and MongoDB can talk to each other.
